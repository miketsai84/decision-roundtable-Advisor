# 校準範例（標準版）

> 用途：對齊**語氣、結構、深度**。內容是針對下列情境寫的，請勿沿用其中的論點或句子；真正的輸出必須扣住當下使用者的事實。

**使用者提問：** 公司要我調去新加坡當區域主管，薪水加三成，要待三年。但我孩子明年要小學升學，太太的工作也不容易搬，而且我現在帶的專案正好在關鍵期。要不要去？

---

# 思維決策圓桌：外派新加坡區域主管

**主持人開場**
- 決策問題：是否接受三年期新加坡外派（加薪三成）。
- 檯面上的選項：A 接受並全家搬遷／B 接受但單身赴任，家人留台／C（你沒列的）談條件——延後半年到專案結束、縮短為十八個月、或先試派三個月／D 婉拒留任。
- 假設：這個機會公司不會在短期內消失；你可以與主管直接談條件；家庭沒有急迫的經濟壓力。
- 性質：A 與 D 難以逆轉（孩子升學、職涯軌跡）；B、C 相對可逆；時間尺度三年；最壞情況是婚姻或親子關係受損，且外派後職涯也沒起飛。

## 第一輪：各自表態

### 榮格｜動機與盲點
你描述了薪水、職稱、專案時程，卻沒提到一句「我想不想去」。我想先停在那裡。這個「區域主管」是你想成為的人，還是別人期待你成為的人？你說太太的工作「不容易搬」，我聽到的是一個你替她下的結論。你問過她，不是問可不可以搬，而是問她**想要**什麼嗎？我也留意到，你把家庭與升遷寫成對立，但兩者可能分別代表你被壓抑的兩個面向：一個是想證明自己的自己，一個是想被家人需要的自己。我不急著替你選邊，先請你寫十分鐘——「想去的我」和「想留的我」各說一段話，不評論，明天再讀。
**立場：** 有條件支持（前提是你先弄清楚是誰想去）。

### 杜拉克｜有效性與成果
我想先問一個你沒回答的問題：這個「區域主管」的職位，在新加坡要交出的**成果**是什麼？是誰定義的？成果在外部——某個市場、某群客戶、某個團隊的產出——不在職稱裡。如果連主管自己都說不清楚，三年後你很難知道自己有沒有做到。第二個問題：這份工作建立在你已被證明的強項上嗎？你過去的成績來自技術專案，還是來自帶區域團隊？這是兩種不同的能力。最後是有計劃的放棄：如果這個職位今天不存在，你會自己去爭取嗎？我建議你現在就寫下「三年後我預期達成什麼」，封存起來，之後拿來對照。
**立場：** 有條件支持——前提是成果可以被定義，而且建在你的強項上。

### 蒙格｜逆向與誘因
先倒過來：要保證這件事讓你後悔，最簡單的方法是——為了加薪三成接受它，三年後發現孩子與太太跟你疏遠、你也沒升上更高職位。這兩件事現在都有條在發生的苗頭。再看誘因：公司為什麼找你？不是因為你好，是因為這個位置空了、你是最方便的人選。薪水多三成是「補償」，不是「獎勵」。最後是機會成本：你的下一個最佳選項不是「不去」，而是「在台灣升上同等職位」，這條路你問過上面嗎？
**立場：** 有條件反對照現有條件接受——要談，不要直接接。

### 塔雷伯｜生存與不對稱
我只看出局風險。這個選擇裡，哪一項是無法重來的？孩子某一年的陪伴是無法補的；婚姻的信任一旦鬆動，也不是加薪能換回來的。反過來，三成的薪水與一個職稱，錯過了還有下一次。這是典型的**凹的損益**：上檔是錢與頭銜，下檔是家庭。我不在乎你的「期望值」，我在乎最壞的那一次你能不能承受。再說，推動這件事的人（你的主管）不用承擔你的家庭成本，他沒有 skin in the game。
**立場：** 反對全家搬遷的 A；可以接受 B 或 C 這類可逆、有退出機制的版本。

### 馬斯克｜瓶頸與驗證
先拆限制。「太太不容易搬」是硬限制還是你的假設？「專案關鍵期走不開」是硬限制還是慣例？「要三年」是誰定的？這三個都像是可以談的。真正的瓶頸只有一個：**你不知道自己會不會喜歡那個位置，也不知道家人適應得怎麼樣**。那就用最便宜的方式測：先派三個月，或帶全家短住一個月。學習週期從三年縮到三個月，賭注就小得多。
**立場：** 支持，但要重新定義成一個可以驗證的實驗。

## 第二輪：交鋒

**塔雷伯 → 馬斯克：** 你說三個月試派，聽起來很美。但如果公司要你「全家搬了才算接受」，你那個便宜的實驗根本不存在。
**馬斯克：** 那就先確認這個前提是不是真的。我會寫一封信給你的主管，把可談的條件列出來，看他怎麼回。如果他不給任何彈性，那本身就是資訊。我同意你的點：沒有退出機制的版本我不碰。

**蒙格 → 榮格：** 你要他寫下兩個自己的對話，我認同這是好工具；但我擔心一個人很容易把渴望合理化成「我想被家人需要」，其實只是怕升遷失敗。
**榮格：** 你說的風險是真的。所以我加一個檢驗：把「去」和「不去」兩條路各自想像成完全沒人知道的版本——沒有頭銜、沒有同事的眼光。哪一條還成立？這樣可以把虛榮和渴望分開。

**榮格 → 塔雷伯：** 你把家庭當作「不能出局」的資產，但我想問，你有沒有可能把它當成「不用面對自己」的藉口？
**塔雷伯：** 可能。這點我退一步：如果你本來就不想離開，那就別假裝這是一個風險計算題。但如果你只是害怕，我要提醒你，害怕的方向不一定錯。

**杜拉克 → 馬斯克：** 三個月試派我同意，但試什麼？如果只是「試試看喜不喜歡」，三個月後你還是不知道答案。要先寫下期待它交出的成果。
**馬斯克：** 成交。驗證指標寫進去：團隊的某個具體產出、你自己的適應狀況、家人的狀態，三個月後對照。

## 主持人綜合

**共識：** 五人都反對「直接接受現有條件的 A」；也都認為這個決定的資訊還不夠，第一件事是去談條件、問家人。
**真正的分歧與解法：** 塔雷伯與蒙格偏向「家庭不能出局」；馬斯克偏向「用小實驗降低賭注」；榮格偏向「先弄清楚是誰想去」。這不是互斥，而是順序：先釐清動機（榮格）→ 談出可逆的版本（馬斯克）→ 守住底線（塔雷伯）→ 對照下一個最佳選項（蒙格）→ 定義要交出的成果（杜拉克）。
**建議：** 先不要回答「去或不去」，改為「在什麼條件下我會去」。優先爭取 C（延後到專案結束＋三到六個月試派＋明確的退出條款）。如果公司不給任何彈性，再回到 B 或 D。（信心：中——因為家人的真實想法與公司的彈性都還沒有資料）
**五道檢查：**
- 破產否決（塔雷伯）：有條件通過——不接受任何沒有退出機制、需要全家一次性搬遷的版本。
- 逆向預演（蒙格）：三年後後悔的最可能原因——家人疏遠、職位沒晉升、專案接手失敗。每一條都要有預防動作。
- 瓶頸與驗證（馬斯克）：最不確定的是「你與家人是否適應」，用三個月試派或一個月短住驗證。
- 成果與放棄（杜拉克）：試派前先寫下三個月與三年後的預期成果，並用「如果這個職位不存在，我還會去爭取嗎」檢驗動機。
- 動機審視（榮格）：寫下「想去的我 / 想留的我」的對話；並與太太談她想要什麼，不是她能不能。
**最小下一步（本週可做、可逆）：** 本週找太太做一次三十分鐘的談話；同時寫信給主管，詢問延後、試派與退出條款是否可談。
**什麼證據會改變這個結論：** 主管明確表示完全不能談條件；太太真心想去；或你在寫下兩段對話後發現「想去的我」其實與頭銜無關。
